## どこで買うかの判断

```decision
そのアーティストの有料ファンクラブに入っている|FC 先行で申し込む。最初に始まり、席も選びやすい
対象 CD を買った・買う予定がある|CD 封入のシリアルコードで先行に申し込む。コード 1 つで申し込める公演・枚数に上限
会員でも CD 購入者でもない|オフィシャル先行(主催者・アーティスト公式の受付)を待つ。会員資格は不要なことが多い
オフィシャル先行に外れた|プレイガイド先行(イープラス・ぴあ・ローチケの抽選)に申し込む。無料会員で可
全部外れた|一般発売(先着)。開始時刻にログイン済みで待つ
行けなくなった|公式リセールに出品する。転売サイトには出さない
```

## 受付の種類と順番

受付はおおむね、対象が狭いものから広いものへ順に進みます。

| 種類 | 誰が申し込めるか | 特徴 |
| --- | --- | --- |
| ファンクラブ(FC)先行 | 有料ファンクラブの会員 | 最初に始まり、良い席が割り当てられやすい。同行者も会員限定のことがある |
| CD封入先行・シリアル先行 | 対象CDを買った人 | CDに入ったシリアルコードで申し込む。コード1つで申し込める公演数・枚数に上限 |
| モバイル会員・アプリ会員先行 | 有料の公式アプリやモバイルサイトの会員 | LDH系など事務所単位の会員制度もある |
| オフィシャル先行・最速先行 [おすすめ] | 誰でも(登録は必要) | 主催者やアーティスト公式が行う受付。会員資格は不要なことが多い |
| プレイガイド先行(プレリク、プレリザーブ 等) | 誰でも(そのプレイガイドの無料会員) | イープラス・チケットぴあ・ローソンチケットなどが行う抽選受付 |
| 一般発売 | 誰でも | 最後の受付。先着が多く、開始数分で埋まることもある |

当サイトのトップにある「販売中のチケット」欄には、このうち**会員資格やCD購入がなくても申し込める受付**(オフィシャル先行・プレイガイド先行・一般発売など)だけを載せています。FC先行やCD封入先行は、各公演のカードの中で確認できます。

## 抽選と先着の違い

**抽選**は、受付期間中ならいつ申し込んでも当落は同じです。締切後に結果が出て、当選したら支払期限までに入金します。期限を過ぎると当選が無効になるので、結果発表日と支払期限は必ず控えておきましょう。

**先着**は、開始時刻から早い者順です。開始と同時にアクセスが集中するため、プレイガイドの会員登録・ログイン・支払い方法の登録を前日までに済ませ、開始数分前にはページを開いて待ちます。

> [!TIP] 先着は「予定枚数終了」で締まる
> 受付期間内でも在庫がなくなれば終了します。当サイトでは、販売ページに終了表示が出た受付を「売り切れ」として表示しています。

## 電子チケット

最近の大規模ツアーはほとんどが電子チケットです。主催者が指定するアプリ(チケプラ、ローチケ電子チケット、ticket board など)をスマートフォンに入れ、申込に使ったアカウントでログインして表示します。

```facts
アプリ|対応 OS とバージョンを事前に確認。古い端末は非対応のことがある
分配|同行者への分配は入場前に済ませる
電波|会場は電波が混む。入場前にチケット画面を開いておく
```

## 公式リセールと転売サイト

行けなくなったときのために、多くのツアーには**公式リセール**(チケプラトレード、ローチケ リセール、イープラス リセールなど)があります。定価で出品・購入できて、電子チケットの名義もきちんと移ります。

> [!WARN] 検索上位の転売サイトに注意
> 「チケット流通センター」「チケジャム」などは公式の申込先ではありません。定価を超える価格の出品が多く、電子チケットでは入場時の本人確認で入れないリスクがあります。チケット不正転売禁止法の対象にもなります。

当サイトでは、収集した申込先が公式のプレイガイド・主催者のページと確認できたものだけをリンクにし、転売仲介サイトやまとめ記事のURLは記録していません。リンクがない受付は、アーティスト公式サイトから申込先を確認してください。

## 申し込む前の確認リスト

```fails
受付の対象を見ていない|会員限定か、誰でもか。同行者の条件もここで決まる
申込枚数と公演の上限を見ていない|1 公演 2 枚まで、コード 1 つで 1 公演のみ、などの制限がある
結果発表日と支払期限を控えていない|抽選は当選しても期限を過ぎると無効
先着の開始時刻にログインしていない|前日までに会員登録と支払い方法を登録し、開始数分前にページを開く
電子チケットのアプリを当日入れる|対応 OS の確認と分配は前日までに
```
