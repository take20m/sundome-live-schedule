# 過去の出演者の見回り(サンドーム福井の次の公演を出演者の側から探す)

以下は過去にサンドーム福井(福井県越前市)で公演した出演者です。
それぞれについて、**今日({{TODAY}})以降のサンドーム福井での公演が発表されていないか**を調べてください。

{{ARTIST_LINES}}

会場名で検索しても、多都市を回る公演の発表では会場が日程表の1行にしか書かれず、検索に出てこないことが多いです。
そのため、会場からではなく**出演者の公式サイトの日程**から当たります。

## 手順(出演者ごと)

1. 公式サイトがあれば WebFetch で開き、LIVE / TOUR / SCHEDULE / NEWS などから、**今後の公演・ツアーの日程ページ**を探して読む
2. 公式サイトが分からない・読めないときは、「(出演者名) ツアー {{YEAR}}」「(出演者名) 公演 福井」等で検索する(1組あたり2回まで)
3. 日程表を最後まで読み、**サンドーム福井**の公演があるか確認する

- 日程表に**サンドーム福井(またはサンドーム)と会場名が明記され、日付が読める**公演だけを記録する。
  「福井公演」とだけあって会場が書かれていない、会場が別の施設(フェニックス・プラザ等)、のどちらかなら記録しない
- 今日より前の公演、過去のツアーの日程は記録しない(検索結果には昔のツアーの記事がよく混ざる。年を必ず確かめる)
- 見つからなければ何も記録しない(何も見つからないのが普通。無理に埋めない)
- 転売・リセール仲介(チケジャム等)、まとめサイト、個人ブログは情報源にしない
- 受付期間が同じページに書かれていれば lotteries に入れてよい。書かれていなければ `lotteries: []`
  (受付期間はこの後の別の工程で調べる)。受付期間は情報源に明記されているものだけ。推測で日時を作らない
- 1組に時間をかけすぎない。全員を一通り見ることを優先する

## 出力

`{{OUT_FILE}}` に保存する(形式は collector/schema.json 準拠)。何も見つからなければ `"events": []` で保存する。

```json
{
  "collected_at": "(実行日時 ISO 8601 +09:00)",
  "events": [
    {
      "title": "(公演の正式名称そのまま)",
      "artist": "(出演者の名義。上の一覧の表記に合わせる)",
      "date": "YYYY-MM-DD",
      "open_time": null, "start_time": null,
      "source_url": "(サンドーム福井の日程が書かれていたページ)",
      "artist_url": "(公式サイトのトップページ。分からなければ null)",
      "tour_url": "(公式サイトのこの公演・ツアーの日程ページ。見つからなければ null)",
      "confidence": "inferred",
      "lotteries": []
    }
  ]
}
```

- 連日公演は日ごとに1件ずつ入れる
- 開場・開演時刻は、その日の値が書かれていれば入れる(他の日の時刻を流用しない)
- 最終出力はファイル保存のみ。標準出力には見つけた公演の一行サマリだけ述べる(なければ「なし」)
